# Agent Workflow Homebrew Tap

Homebrew Formula for [Agent Workflow](https://github.com/Geoege-xll/agent-workflow).

## Install

```bash
brew install Geoege-xll/tap/awf-cli
awf-cli
```

## Upgrade

```bash
brew update
brew upgrade Geoege-xll/tap/awf-cli
```

Homebrew manages the central program and its Python dependency. It does not sync or
upgrade project workflows automatically, edit your shell configuration, or remove
commands installed separately from the source package. Check `type -a awf-cli` if
an older command takes precedence. Do not run `awf-cli --install-cli` for the
Homebrew-managed installation.

For installation boundaries and release instructions, see the
[Homebrew guide](https://github.com/Geoege-xll/agent-workflow/blob/main/docs/homebrew.md).
